UK Law MCP server

A free, read-only MCP server that lets AI assistants search and read all UK legislation — about 130,000 Acts and regulations, updated daily from legislation.gov.uk — and answer with the exact section and the official link.

Server URL:

https://uk-law-mcp.example.workers.dev/mcp

Claude (claude.ai and Claude Desktop)

Settings → Connectors → Add custom connector. Name it "UK Law" and paste the server URL. No sign-in is needed.

ChatGPT

Settings → Apps & Connectors → Advanced → turn on Developer mode, then Create a connector with the server URL and "No authentication". Availability depends on your ChatGPT plan.

Claude Code

claude mcp add --transport http uk-law https://uk-law-mcp.example.workers.dev/mcp

Codex

Add to ~/.codex/config.toml:

[mcp_servers.uk-law]
url = "https://uk-law-mcp.example.workers.dev/mcp"

Tools

  • search_laws — find laws by title words or id, with filters (type, in force, extent, topic)
  • get_law — read a law, or one section, schedule or part of a long one
  • list_topics, get_topic — laws in force by subject

Then ask: "What does the Employment Rights Act say about notice periods?"

About

The data is the UK Law repository; there is also a Claude Code plugin that works without this server. Built and maintained by Tavlabs Ltd, London.
