UK Law MCP server

A free, read-only MCP server that lets AI assistants search and read all UK legislation — about 130,000 Acts and regulations, updated daily from legislation.gov.uk — and answer with the exact section and the official link.

Server URL:

https://uk-law-mcp.example.workers.dev/mcp

Claude (claude.ai, Claude Desktop, mobile)

  1. Open Customize → Connectors.
  2. Click + Add → Add custom connector.
  3. Name UK Law, paste the server URL, click Continue.
  4. Authentication: No sign in, then Add.
  5. In a chat: + → Connectors → make sure UK Law is on.

Free plan: one custom connector. Team/Enterprise: an Owner adds it in Organization settings → Connectors.

ChatGPT

chatgpt.com (web) with a Pro, Business or Enterprise/Edu plan; on Business only admins and owners can add it.

  1. Open Plugins, click + → Add custom MCP server.
  2. Name UK Law; under Connection, paste the server URL; authentication None.
  3. Tick I understand and want to continue, click Create as a plugin and install it.
  4. In a new chat, type @, pick UK Law and ask.

Free and Plus: paste https://raw.githubusercontent.com/flaviohtavares/uk-law/main/llms.txt into the chat instead.

Claude Code

claude mcp add --transport http --scope user uk-law https://uk-law-mcp.example.workers.dev/mcp

Or the plugin: /plugin marketplace add flaviohtavares/uk-law-tools then /plugin install uk-law@uk-law-tools.

Codex

codex mcp add uk-law --url https://uk-law-mcp.example.workers.dev/mcp

Check with codex mcp list. Full guide: github.com/flaviohtavares/uk-law-mcp.

Tools

  • search_laws — find laws by title words or id, with filters (type, in force, extent, topic)
  • get_law — read a law, or one section, schedule or part of a long one
  • list_topics, get_topic — laws in force by subject

Then ask: "What does the Employment Rights Act say about notice periods?"
